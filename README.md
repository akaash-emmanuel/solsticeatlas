# Solstice Atlas

A 3D Interactive Earth and Solar System Visualization.

## Setup

1.  **Install Dependencies**:
    ```bash
    npm install
    ```

2.  **Environment Variables**:
    *   Copy `.env.example` to `.env`:
        ```bash
        cp .env.example .env
        ```
    *   Add your OpenAI API Key to `.env`:
        ```
        OPENAI_API_KEY=sk-...
        ```

3.  **Run Development Server**:
    ```bash
    npm start
    ```

## Features
- **Solar System**: Accurate planets, moons, and cinematic effects.
- **AI Command**: "Take me to Mars", "Filter Quakes".
- **Predictive Engine**: Real-time risk analysis.
